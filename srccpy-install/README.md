# srccopy-install (archlinux)

You want to play android games in your linux (arch?) using an automated install and run scripts. This is the place.

# Features

This includes native controller remapping option
(xbox controllers support so far) that remaps natively your controller to the android app/game input.
No superficial remapping apps behavior.

Planned features:
- Playstation controllers support
- More configuration 
- Possibly, make this a full CLI app. 
- Add wiki/md's.md documentation. (For now, all docs are simple comments in installing.sh)

# Why
I wanted to play some android games using srccopy due to some emulation problems I had with waydroid. So I thought, why not with src-copy?, then I found is kinda problematic to remap controllers using it and some performance issues. I think is ok this way.
