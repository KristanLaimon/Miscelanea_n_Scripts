# Miscelanea projects

Small projects I keep in one repository. Each folder has its own code and setup; build output and local tooling stay out of Git.

## [KaraokeDJ](KaraokeDJ/)

A karaoke video editor with timed lyrics, a timeline, project saving and video export. Runs on Windows and Linux, with a browser editor too.

Stack: Rust, egui/eframe, wgpu, FFmpeg, WebAssembly.

## [ClickProofer](ClickProofer/)

Filters unwanted rapid repeat mouse clicks on Windows. Includes a click recorder to measure the problem and help choose a threshold.

Stack: Rust, Windows API, Python, Tkinter.

## [Greppy](Greppy/)

A small grep-like command that searches piped text. Supports case-insensitive matching. My first Rust learning project, with no dependencies.

Stack: Rust standard library.

## [luex](luex/)

A component compiler and reactive UI runtime for Neovim. Turns Svelte-, React- and Vue-style components, plus its own component format, into Lua modules.

Stack: Lua, Neovim, Bash, PowerShell.

## [srccpy-install](srccpy-install/)

Scripts to install and run scrcpy on Arch Linux, with native Android gamepad input and Xbox controller remapping.

Stack: Bash, scrcpy, ADB, C, SDL3.


## [koreder-patches](koreader-patches/)
Some .lua files patch for recent koreader versions, for my e-readers

Stack: lua (JIT 5.1 Compatible syntax)
